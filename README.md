# MLR-sleep-quality
A final project for STAT 3640 - Foundations of Data Analysis. 

## Sleep Quality & Lifestyle: Multiple Linear Regression Analysis
Analyzed lifestyle and health predictors of sleep quality using multiple linear regression in R.

**Dataset:** Kaggle Sleep Health and Lifestyle Dataset (n = 374)  
**Tools:** R, base stats, car package  
**Key finding:** Stress level was the strongest negative predictor of sleep quality; overweight/obese BMI was also significant.  
**Model fit:** Adjusted R² = 0.944

### Files
- `sleep_analysis.R` — model fitting and assumption checks
- `sleep_data.csv` — dataset
